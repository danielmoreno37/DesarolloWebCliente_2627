Definiciones y conceptos

Diseñar una lista de definiciones con los siguientes conceptos

  • URL

    Una URL es la dirección web única que sirve para localizar un recurso en Internet (como una página o imagen) e indicar al navegador qué protocolo usar para abrirlo.

  • HTTP

    HTTP Hypertext Transfer Protocol es el protocolo de red que permite la transferencia de información y datos en la Web. Funciona mediante un sistema de petición-respuesta entre el navegador del usuario y el servidor que aloja la página.

  • TCP/IP

    TCP/IP es el conjunto de protocolos de red fundamental que permite la comunicación y el envío de datos entre ordenadores en Internet. Se encarga de dividir la información en paquetes, enviarla de forma segura y asegurarse de que llegue a su destino correcto.

  • Internet

    Internet es una red global descentralizada de ordenadores e interconectada mediante el protocolo TCP/IP. Permite el intercambio libre de datos y el acceso a servicios como la Web (HTTP), el correo electrónico o la transferencia de archivos.

  • W3C

    El W3C World Wide Web Consortium es el organismo internacional de estandarización que desarrolla las normas y recomendaciones para asegurar el crecimiento ordenado y la accesibilidad de la Web a largo plazo (creadores de estándares como HTML y CSS).

  • HTML

    HTML HyperText Markup Language es el lenguaje estándar utilizado para estructurar el contenido de las páginas web mediante etiquetas. Define elementos como textos, imágenes, enlaces y formularios para que los navegadores puedan interpretarlos y mostrarlos.
